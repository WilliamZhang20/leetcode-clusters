Select tags to highlight overlap. Match all shows the intersection; match any shows the union. Other problems stay on the map, dimmed.

How similarity works

Two problems are similar when their topic tags overlap. The score is Jaccard similarity: shared tags divided by the tags on either problem.

If they already share a tag and sit in the same difficulty band, the score gets +0.05, capped at 1. Tags decide the grouping. Difficulty is only a nudge.

Tags are topic filters. The cluster directory groups nearby map bubbles using an adjustable distance threshold. A problem belongs to one spatial group at a given threshold, and can carry several topic tags. Tags sit on a ring, ordered so tags that share problems are neighbors. A problem is drawn at the weighted center of its tags. Rarer tags pull harder, so a broad label such as Array does not pile unrelated questions together. Questions whose tags are neighbors land in that part of the ring; questions whose tags are far apart sit between them.

A line is a high-scoring pair. Lines are drawn for the bubble under the pointer, and among the problems on screen when that neighborhood is small enough to read.
